## Featured Projects

### [FlowCali — Computer Vision Exercise Analysis](https://github.com/Logan-McKinney/flowcali-showcase)
A mobile application that analyzes calisthenics videos and produces repetition-level form feedback. Built with **React Native, FastAPI, MediaPipe Pose, OpenCV, Celery, Redis, PostgreSQL, and S3**, with structured AI-generated coaching. The showcase includes an actual iPhone walkthrough, skeleton-overlay footage, system architecture, and a runnable synthetic rep-segmentation demo. The production application remains private.

### [rPPG Research — Physiological Signal Estimation](https://github.com/Logan-McKinney/rppg-research-portfolio)
Collaborative **deep learning and signal-processing research** on estimating pulse signals from facial video under motion and illumination changes. My contributions include configurable facial ROI extraction, integrating collaborators' motion features into the training pipeline, debugging preprocessing and model behavior, and analyzing experiments. The repository includes the research models, documented ablation results, figures, and contributor attribution.
